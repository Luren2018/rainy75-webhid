RAINY 75 / 连接与适配BROWSER FIRST

默认使用浏览器 WebHID。选择型号后点击页面右上角“连接键盘”，并在桌面 Chrome / Edge 的设备选择框中授权。需要本机服务时可切换为本地直连。RGB 与无光版共用设备 ID，请按实际型号选择。

适配说明

已内置文件包里的 USB / 2.4G、RGB / 无光版定义，使用 8 × 16 矩阵与块读写协议。接入时读取设备实际层数。

此版本适用于 VIA 固件；官方自研驱动固件是另一套协议，不会自动刷写或切换固件。蓝牙连接、固件升级与宏编辑暂未提供。
